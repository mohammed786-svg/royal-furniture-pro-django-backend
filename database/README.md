# Database SQL Assets

| Directory | Purpose |
|-----------|---------|
| `migrations_sql/` | Full schema (`royal_furniture.sql`) |
| `sql/` | Domain query files |
| `functions/` | PostgreSQL functions |
| `procedures/` | Stored procedures |
| `views/` | Materialized / regular views |
| `triggers/` | Triggers |
| `indexes/` | Supplemental indexes |

Apply schema:

```bash
./scripts/apply_schema.sh
```
